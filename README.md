## 브랜드 포지셔닝

치즈박스는 단순 포토부스 렌탈 업체가 아니다.

행사의 목적과 브랜드 메시지를 분석하고,
현장에서 참여 경험을 설계하는 프리미엄 브랜드 경험 파트너다.
